# AGENTS.md

## General Rules

- Inspect the repository and relevant files before making changes.
- Respect the existing project structure, conventions, and documented decisions unless explicitly instructed otherwise.
- Do not invent product requirements, architecture decisions, implementation details, or project state that are not supported by the repository or explicit instructions.
- Keep changes narrow and scoped to the requested task. Avoid unrelated refactors, speculative abstractions, or premature infrastructure.
- Prefer incremental, reviewable changes over broad rewrites.
- When sources conflict or the intended behavior is unclear, surface the conflict instead of silently making assumptions.
- Treat historical logs, snapshots, handoff notes, archived files, and outdated documentation as supporting context rather than automatically assuming they describe the current state.
- Preserve existing files and content unless modification is necessary for the requested task.
- After making changes, inspect the resulting diff and run relevant validation when available.
- Clearly report what changed, what was validated, and any unresolved issues.
- Do not commit, push, amend, rebase, reset, or otherwise modify Git history unless explicitly approved.
